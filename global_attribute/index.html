lests learn global attributes

| Attribute | What it does | | ------------- | ------------------------------------------------------ | | **class** | Used to define classes for CSS styling / JS selection | | **id** | Unique identifier for an element | | **style** | Adds inline CSS style to an element | | **title** | Adds a tooltip text when you hover on the element | | **hidden** | Hides the element from the page (but still in HTML) | | **lang** | Defines language of the element’s content | | **dir** | Direction of text (ltr or rtl) | | **data-*** | Custom data attributes (e.g., `data-title`, `data-id`) | | **draggable** | Makes element draggable (true/false) | | **tabindex** | Specifies the order when using Tab key navigation |
